## Що вже готово (бекенд-основа)

- Каталог, PDP, кошик, wishlist, Sale, checkout
- Auth (bcrypt + cookie), кабінет
- **SQLite БД**: товари, варіанти (колір×розмір×сток), замовлення, платежі (hash), wishlist, тікети
- Адмінка пише **в базу** (не в localStorage)
- Локально: http://127.0.0.1:3847 · адмін: `/admin`

| Email | Пароль | Роль |
|-------|--------|------|
| `demo@blanco.ua` | `demo1234` | USER |
| `admin@blanco.ua` | `demo1234` | ADMIN |

### Адмінка → база

**Так:** зміни в адмінці (товар, ціна, сток, статус замовлення, галерея) йдуть через API в SQLite.

### Сток колір × розмір

**Так:** окремий залишок на пару (колір + розмір). Після замовлення сток зменшується.

**Ні, не WebSocket live:** інший клієнт бачить оновлення після refetch (PDP: focus + кожні 20с).

## База локально

- Файл: `prisma/dev.db`
- GUI: `npx prisma studio` → http://127.0.0.1:5555
- Схема: `prisma/schema.prisma`
- Seed: `npm run db:seed`
- Фото з сирих JPG: `npm run images:galleries`

На сервер: той самий Prisma schema → PostgreSQL (`provider = "postgresql"`) + `migrate deploy`.
